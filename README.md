# 个人信息自动填写助手

一个无需构建、可直接加载到 Chrome 或 Edge 的 Manifest V3 浏览器扩展。

## 安装

### Chrome

1. 地址栏打开 `chrome://extensions/`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择当前文件夹 `autofill-extension`。

### Edge

1. 地址栏打开 `edge://extensions/`。
2. 打开左侧「开发人员模式」。
3. 点击「加载解压缩的扩展」。
4. 选择当前文件夹 `autofill-extension`。

## 使用

1. 点击工具栏中的扩展图标，再点击「管理个人资料」。
2. 资料管理页可保存基础信息、多条教育经历、工作/实习经历、项目经历、校外实践、奖励信息、家庭成员和自定义项目。教育经历还包括学制、绩点、是否海外教育经历、导师和实验室；校外实践包括起止日期、单位或部门、主要内容。基础信息还包括民族、党派、婚姻状况、户籍、籍贯、生源地、出生地、身高、体重、健康状况、特长、工作年限、紧急联系人、现居住地及求职意向；奖励信息包括名称、级别、时间和说明；家庭成员包括姓名、关系、出生日期、性别、是否移动系统内任职、工作单位、职位、联系电话、政治面貌和现居住地址。
3. 自定义项目用于员工编号等零散字段，支持搜索和行式编辑。多个匹配关键词之间使用空格分隔，例如 `工号 employee-number staff-id`。最多可保存 500 个自定义项目；旧的逗号分隔格式会自动整理为空格。
4. 回到招聘网页，点击「一键填写个人及自定义信息」只填写这两类资料，不会自动填教育、工作、项目、校外实践、奖励或家庭成员。
5. 要填写一条经历、奖励或家庭成员：先在招聘网页自行点击「新增」并打开空白表单，再在插件的「逐条填写」列表中点击对应资料。教育、工作/实习、项目、校外实践和奖励信息只会填入当前视口中正在展示的编辑器，不会回退填写滚动区域外或其他页面中的唯一表单；如果当前同时显示多个同类表单，先点击目标表单中的一个输入框，再点击插件资料。无法确定目标时插件会提示，不猜测第一条。
6. 插件不会在打开网页时自行填写；所有填写都要在弹窗中手动触发。

### DeepSeek AI 辅助（3.1.0）

在「管理个人资料 → 相关设置」填入自己的 DeepSeek API Key、开启「DeepSeek AI 辅助填写」，保存后可点「测试连接」。启用后，每次点击一键或逐条填写都会调用快速非推理模式的 DeepSeek `deepseek-flash` 重新判断当前网页字段；不会在打开网页时自行调用。若 AI 不可用，本次填写会停止并提示，避免在不知情的情况下改用另一套匹配结果。关闭开关即可继续使用原有本地规则。

AI 辅助判断“哪块是目标经历表单”以及“网页字段对应哪项资料”，实际填写仍在本地完成。经历表单的本地定位规则失败或发现多个候选时，AI 会根据区域标题和字段标签选择目标；高置信且唯一的目标可继续填写，多个相似区域或低置信结果会在网页右下角请你确认，不能确定时不会猜选。先点击目标输入框仍有助于锁定区域。高置信且没有冲突的字段可自动填写；不确定的字段映射会逐项显示供你确认。网页已有内容默认不会覆盖，需在对应字段单独勾选允许覆盖；不同经历的名称冲突会停止。你确认的字段映射保存在本地，后续仍会由 AI 重新检查。请在网页上复核结果，并自行点击招聘网站的保存或提交按钮。插件已支持 Ant Design、Element UI 及常见通用只读日期选择器；常见地址级联控件会按省、市、区县逐级选择，仍无法确认的专用控件会保留给人工处理。

从 3.4.0 开始，填写链路先建立控件能力模型，再执行“复合字段拆分与精度适配”。同一条完整日期可按网页结构投影为单个年月日字段、年月字段、仅年份字段，或“开始年 / 开始月 / 结束年 / 结束月”等多个独立控件；地区资料也会按目标控件自动投影为省、省市或省市区。规则引擎先处理可以确定的结构，DeepSeek 只补充未知区域与字段语义，避免让 AI 直接操作网页控件或猜测资料值。

DeepSeek API 是第三方云服务，调用可能产生费用。当前扩展不会把资料填写值、已有网页输入值或完整简历发送给 DeepSeek；定位请求仅包含候选区域标题、字段标签和控件类型，字段映射请求包含当前表单的字段标签、控件类型、下拉选项、可用资料项名称、自定义项目名称与关键词，以及本地记住的字段对应关系。网页标题、标签和下拉选项本身若含个人信息，也会作为表单结构发送；请确认可以接受后再启用。API Key 保存在浏览器扩展的本地存储中，未加密，也不经过本插件开发者的服务器。

教育、工作、项目和校外实践的起止时间、奖励时间，以及个人与家庭成员的出生日期，均可在资料管理页选择到“日”。网页字段支持完整日期时填写年月日；网页只接受年月时自动省略“日”。升级前保存的 `YYYY-MM` 起始时间会显示为当月 1 日，结束时间会显示为当月最后一日；如有准确日期，可在资料管理页修改并保存。

随扩展附带的 `demo.html` 可用于测试一键填写和逐条选择；页面中的示例按钮也可独立验证目标定位和学历阶段保护。

## 隐私与安全

- 个人资料及 AI Key 保存在浏览器的 `chrome.storage.local`。AI 关闭时不请求云服务；启用后，用户每次触发填写会向 DeepSeek 发送上述表单结构并取得映射。API Key 还会用于「测试连接」。
- 插件不会在页面加载时自动填写。
- 默认不会覆盖网页中已有的内容。
- 永远跳过密码、验证码、银行卡、信用卡与交易相关字段。证件类型和证件号码可由用户主动保存和填写。
- 扩展需要在网页中运行内容脚本，才能识别并填写表单；浏览器内部页面（如设置页、扩展商店）不允许扩展运行。

## 支持字段与经历

内置支持姓名（完整姓名、姓、名、昵称）、性别、出生日期、证件类型、证件号码、电子邮箱、手机号码、微信号、个人主页、地址与补充地址、城市、省/州、邮编、国家/地区、户籍、籍贯、生源地、出生地、现居住地、身高、体重、健康状况、特长、工作年限以及紧急联系人姓名和电话。结构化资料支持多段教育、工作/实习、项目、校外实践、奖励信息及家庭成员；零散字段还可以通过自定义项目补充。

户籍、籍贯、生源地、出生地和现居住地建议按“省 / 市 / 区县”填写。保存时插件会同时保留原始文字并生成省、市、区三级结构；网页是普通输入框时写入完整地址，是多个独立下拉框时分别选择对应层级，是常见组件或招聘网站自研的行政区弹层时依次选择。网页只支持省市两级时会在选择到市后结束，不会因资料还包含区县而误报失败。旧版本保存的连续文字（例如“山西省晋中市平遥县”）会在填写时自动拆分，无需重新录入。

复合日期控件会根据标签、占位文案、选项范围和排列顺序识别年、月、日槽位；“起止时间”中重复出现的年份或月份会自动切换到结束日期。网页只有“年”或“年 + 月”时只填写可表达的精度，不会把完整日期字符串写进单个槽位。字符数提示等辅助文字会从字段标签中剥离，因此“最多 60 个字 / 工作描述”这类结构仍能识别真正的字段名。

未启用 AI 时，识别会优先使用标准 HTML `autocomplete` 属性，再结合字段类型、名称、ID、占位文案、无障碍标签和表单标签进行判断。中文标签中的空格和必填符号会被忽略，例如“姓 名”“证 件 号 码”“邮 箱”均可正常识别。自定义项目会使用项目名称及用户设置的关键词进行匹配。扩展也会触发 `input`、`change` 和 `blur` 事件，以兼容 React、Vue 等前端框架的受控表单。

对于标签没有正确关联输入框的旧式网页，扩展会从最近的表单分组或表格单元格读取可见标签。逐条填写会先识别资料类别及当前视口中的表单，再结合用户最近点击的输入框锁定目标；多个候选且没有明确目标时会停止。高校资料不会填入明确标识为高中的表单，反之亦然。

插件不会替用户点击招聘网站的“新增”“保存”或“提交”。原生下拉框支持常见学历和工作形式的同义选项，自定义下拉框会尝试搜索并选择最接近的选项。部分网站的级联地址、专业、日期组件或登录后专用控件仍可能需要手动处理和确认。

中国移动校园招聘简历页（`job.10086.cn/personal/resume_campus.html`）的家庭成员区域已单独适配。请先在网页点击“添加”打开家庭成员编辑表单，再在插件里选择对应的家庭成员；插件会填写文本、关系/性别/政治面貌等下拉框、出生日期与省市区地址，不会代点网页的“保存”。找不到完全对应的下拉选项或地区时会跳过该项；“是否移动系统内任职”为“是”时，网页额外要求“亲属所在部门”，需手动补充。

51job 承载的简历页（`xyz.51job.com/External/MyResume/FillInResume.aspx`）“科研项目或研究经历”表单已单独适配。网页上同时有多条项目时，先点击要填写的那一条中的输入框，再在插件里点对应项目；未指定目标不会猜测，已有不同项目名称的表单也不会被覆盖。插件按“项目名称→项目名称”“项目职责→项目角色”“工作描述→项目描述”及起止日期分别填写，日期控件会写入完整年月日并校验显示值。请核对内容后手动保存；不同页面模板或网站校验逻辑仍可能需要手动处理。

同一 51job 简历页的“家庭成员情况”也已单独适配。先在网页自行点击“添加”打开家属表单；若同时显示多条家属，先点击目标家属表单中的输入框，再在插件里点对应记录。姓名不同的已有家属不会被覆盖。插件会处理亲属关系、性别、是否系统内任职、政治面貌等下拉项，以及只读出生日期、省市联动地址和文本字段；网页没有可精确匹配的选项时会跳过，不会猜选。若资料地址还包括网页没有输入框的区县或详细地址，请手动补充并核对后保存。

中国工商银行招聘简历页已纳入通用字段语义样本，包括高校与高中教育表单。填写结果仍以用户当前打开的页面结构为准；插件不保证每个招聘网站的专用控件都能自动填写。

智联招聘承载的校园招聘简历页已适配 Element UI 只读日期选择器。实习经历的入职、离职日期会通过网页日期面板选择并校验结果，而不是直接修改只读输入框；插件仍不会代点经历的保存或提交。
